## Wi-Fi Lab для OpenWrt 25.12

LuCI-интерфейс для мониторинга собственных Wi-Fi сетей. Сканирование эфира, сведения о защите и WPS, список замеченных клиентов, запись CAP с проверкой WPA-handshake и управляемый deauth для тестовых устройств.

В релизе находятся APK и файл контрольной суммы SHA-256. После проверки суммы перенесите APK на роутер и установите его через `apk add --allow-untrusted ./имя-пакета.apk`. Приложение появится в **Services → Wi-Fi Lab**.

Переключение выбранного радио в monitor mode временно прерывает работу его точки доступа. Для управления используйте Ethernet. Пакет проверен на OpenWrt 25.12.6 x86/64 с MediaTek MT7921 и драйвером `mt7921e`.
